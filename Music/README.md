# Music — 音乐库

把音乐文件放入本文件夹，网站会**自动读取并加入音乐库**播放。

## 命名规则（重要）

歌曲文件请命名为 **`歌名+歌手名.mp3`**，网站据此自动解析出「歌名」与「歌手」：

```
少年歌行+张赫宣.mp3      →  歌名：少年歌行   歌手：张赫宣
人间惊鸿宴+指尖笑.mp3    →  歌名：人间惊鸿宴  歌手：指尖笑
如歌+JandZ.mp3          →  歌名：如歌      歌手：JandZ
```

- 分隔符用 **`+`**（也兼容 `-`、`_`）。
- 支持格式：`.mp3`、`.m4a`、`.ogg`、`.wav`。
- 歌名 / 歌手名可含中文、英文、数字。

## 如何添加歌曲

1. 将歌曲按 **`歌名+歌手名.mp3`** 命名，放入本 `Music/` 文件夹。
2. **更新清单**（让网站在任何环境下都能读到）：在 `poemweb` 目录下运行
   ```
   node tools/scan-music.js
   ```
   该命令会重新扫描本文件夹，生成 `Music/index.json` 与 `data-music.js`。
3. 刷新网页即可在「点歌台」看到新歌，右上角随机播放也会包含它。

> **免命令提示**：如果你的网站部署在**支持目录列表**的静态服务器上（如 `python -m http.server`、nginx autoindex），网站会**直接读取 `Music/` 文件夹**自动识别新增歌曲，**无需运行上面的命令**，刷新即可。

## 读取机制（三级）

1. 直接读取 `Music/` 目录列表（支持目录列表的服务器，自动识别新歌）
2. 读取 `Music/index.json` 清单（任何静态主机可用）
3. 回退 `data-music.js`（用 `file://` 直接打开网页时可用）

## 说明

- 顶栏右上角「♪」随机播放，曲终**自动接下一首**。
- 「点歌台」页支持按**歌名 / 歌手名**搜索、点歌、上一首 / 下一首 / 随机切换。
- 浏览器自动播放策略限制：音乐需**点击**（右上角 ♪ 或点歌台）才会响起，无法打开页面就自动播放。
